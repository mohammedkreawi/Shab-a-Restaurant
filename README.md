# نظام شبعة لطلبات المطاعم

مشروع واجهات أمامية فقط باستخدام HTML5 وCSS3 وJavaScript Vanilla.

## التشغيل
1. فك ضغط الملف.
2. افتح `index.html` في المتصفح لواجهة الزبون.
3. افتح `admin.html` في تبويب آخر للوحة المطعم.
4. جرّب إضافة وجبات وتأكيد طلب، ثم راجع ظهوره في لوحة المطعم.

## هيكل الملفات
- `index.html`: واجهة الزبون.
- `admin.html`: لوحة إدارة المطعم.
- `css/style.css`: الهوية البصرية والتنسيق المتجاوب.
- `js/app.js`: بيانات الوجبات والسلة والطلبات والتفاعلات والتخزين المحلي.

## ملاحظات مهمة
- تتم مشاركة البيانات التجريبية عبر `localStorage` في نفس المتصفح ونفس النطاق/الأصل.
- افتح الملفين من نفس المسار، ويفضل استخدام إضافة Live Server في VS Code لتشغيلهما على نفس العنوان المحلي.
- هذه نسخة Front-End تجريبية وليست نظاماً إنتاجياً؛ لا يوجد خادم أو قاعدة بيانات أو تسجيل دخول حقيقي.
- صور الوجبات والخط تُحمّل من الإنترنت، لذلك يلزم اتصال بالإنترنت لعرضها. يمكن استبدال روابط الصور بصور محلية.
